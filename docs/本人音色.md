# 本人音色（声音克隆）

用本机显卡跑开源模型 **Qwen3-TTS 0.6B**（Apache-2.0，可商用），用一段 10–20 秒的本人录音克隆音色，配音模式的项目写 `"voice": { "engine": "clone" }` 就用本人声音配音。

## 每台电脑装一次

模型和环境大约 **5GB**，不放在仓库里（GitHub 单文件上限 100MB）。**你的录音也绝不能放进仓库**：仓库是公开的，任何人拿到录音都能克隆你的声音。

```bash
node bin/mjv.mjs voice install                 # 装到 F:/mjv-voice（没有 F 盘就装到用户目录），--dir= 可改；需要联网，十几分钟
node bin/mjv.mjs voice setup --ref="E:/公司工作区/视频制作规范/01_声音/本人原录音_克隆首选_24k.wav"
node bin/mjv.mjs voice test                    # 出一段试音 → ~/.mjvideo/voice_test.wav，听一下
node bin/mjv.mjs doctor                        # 检查，"本人音色"一项应该是 ✓ 或 ⚠
```

- 显卡：有 NVIDIA 显卡会装 CUDA 版（RTX 50 系必须用 CUDA 12.8 版，安装脚本已处理），一句话一两秒。没有 N 卡也能装（`--cpu`），但几十秒一句。
- 网络：模型从 Hugging Face 下载，连不上会自动改用国内镜像 hf-mirror.com。
- 本机配置在 `~/.mjvideo/voice.json`，参考录音复制在 `~/.mjvideo/ref.wav`，都不在仓库里。

## 逐字稿（影响相似度）

模型最好同时知道参考录音里**逐字说了什么**。`voice setup` 没给 `--text` 时会自动转写一份**草稿**，但机器转写会有错字，所以先用"只取音色特征"模式（相似度略低）。
请本人听一遍录音、把草稿改对，然后：

```bash
node bin/mjv.mjs voice status                  # 看草稿（ref_text_draft）
node bin/mjv.mjs voice setup --text="改好的、逐字准确的文字"
node bin/mjv.mjs voice test
```

## 项目里怎么用

```jsonc
"voice": { "engine": "clone", "fallback": "edge", "voice": "zh-CN-YunxiNeural", "rate": "+6%" }
```
- `fallback`：这台电脑没装本人音色时，改用微软 AI 声音（`voice` 是 AI 声音的音色），命令行会醒目提醒，项目里留下 `build/audio/VOICE_FALLBACK.txt`。不写 `fallback` 就直接报错。
- 本人音色没有逐词时间，字幕按字数在整句里均分。
- 改了参考录音或逐字稿，所有用本人音色的镜头会自动重新合成（缓存键里带了它们）。

## 给 Agent

- 开工前跑 `node bin/mjv.mjs doctor`（MCP：`mjv_doctor`）。"本人音色"不是 ✓ 时**告诉用户**，不要默默用 AI 声音交付。
- `voice install` 要下载约 5GB：**先问用户同意**再装。
- 交付时说明这一期用的是本人音色还是 AI 声音（看有没有 `build/audio/VOICE_FALLBACK.txt`）。
