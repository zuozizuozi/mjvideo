# 视觉手法：把一句话变成一个画面

给写美术方案和场景代码的 Agent 看。SKILL.md 讲"规则"，这里讲"怎么想、怎么做"。
**这里的例子是启发，不是模板**：看懂思路，然后为你这条视频想新的。

---

## 一、从一句话到画面：四步

1. **找主角**：这句话里最重要的名词是什么？（"它只会猜**下一个字**"→ 主角是"下一个字"）
2. **找关系**：主角在发生什么？是变多 / 变少、对比、流动、分叉、聚合、断裂、循环、因果，还是先后？（"猜"= 从几个候选里挑一个 → **分叉后收拢**）
3. **选比喻家族**：用观众生活里见过的东西来演这个关系（见第二节）。同一个关系可以有很多比喻，**先列三个再挑**：
   - 挑一个 → 抽签筒里抽签 / 老虎机停在一格 / 岔路口选一条 / 概率条最长的那根飞出去
4. **让它动起来**：动作要对上字幕里的那个词出现的时刻。**画面不动等于没讲**；观众要能不看字幕也大致看懂。

自检：把字幕遮住，只看画面，能猜出这一镜在讲什么吗？猜不出就换比喻。

---

## 二、比喻库（按"要讲的关系"分）

| 要讲的关系 | 可以用的画面（挑一个，或者想新的） |
|---|---|
| **数量级、规模大** | 一个点拉远成星海；一粒沙变成沙漠；一页纸叠成一座山；计数器飞涨到看不清；一个人站在巨物脚下 |
| **对比、真假、新旧** | 左右分屏同步做同一件事；同一个东西换两种光照；天平；镜像；"找不同"的两张卡 |
| **过程、步骤、流程** | 传送带 / 流水线；多米诺骨牌；接力赛；一条路上的路标依次亮起；齿轮带动齿轮 |
| **随时间变化、积累** | 年轮一圈圈长出来；沙漏；植物生长；水位上涨；照片褪色 / 显影 |
| **因果、连锁反应** | 推倒第一块骨牌；涟漪扩散；一根线拉动另一头；开关一按灯一排排亮 |
| **不确定、概率、猜** | 骰子；抽签；雾里的路；天气预报的百分比；转盘停下；多条虚线轨迹只实了一条 |
| **错误、幻觉、编造** | 拼图里一块颜色不对但形状严丝合缝；镜子里的倒影和本体不一样；印章盖在空白纸上；地图上画着一座不存在的岛 |
| **层级、结构、拆解** | 俄罗斯套娃；洋葱一层层剥开；建筑剖面图；爆炸图（零件飞散又组装回去） |
| **关系、连接、网络** | 星座连线；地铁线路图；红线串起照片墙；神经元放电；蜘蛛网被拨动 |
| **记忆、遗忘、容量** | 抽屉塞满后旧东西被挤出去；黑板写满后擦掉开头；褪色的照片；沙滩上的字被浪抹掉 |
| **学习、纠错、变好** | 小球滚下山谷；射箭慢慢靠近靶心；陶艺拉坯一点点成形；草稿纸上的划掉重写 |
| **情感落点（结尾）** | 光点汇成人形；两只手；一盏灯在窗口亮起；镜头拉远到很小的一个人；从画面里走出来回到现实 |

AI 话题常用的主角，可以这样"具象化"：
- 模型 / 参数 → 旋钮墙、调音台、一整面开关、密密麻麻的光点
- 训练数据 → 图书馆、文字雨、海量书页、河流
- 词元 token → 拼图块、积木、乐高、珠子
- 注意力 → 聚光灯、视线连线、放大镜
- 生成 → 打字机、织布机、一笔一笔画出来
- 上下文窗口 → 手电筒照亮的一小段路、火车车厢、能装下的一个背包

## 三、动效语言（整片选 2–3 种，统一使用）

| 家族 | 出现 | 离开 | 适合的气质 |
|---|---|---|---|
| **生长** | 从一点长出来、线条沿路径画出、枝杈蔓延 | 枯萎、收回 | 自然、成长、学习 |
| **聚散** | 粒子从四周聚成形 | 碎成粒子散开 | 宇宙、哲思、科技 |
| **纸片** | 翻页、折纸展开、贴纸拍上去（带一点回弹） | 撕掉、翻走 | 手作、亲切、清单 |
| **机械** | 滑轨推入、齿轮咬合、卡扣弹出 | 退回轨道 | 工程、流程、原理 |
| **印刷** | 印章盖下、网点显影、逐行打印 | 墨迹晕开 | 复古、新闻、档案 |
| **光** | 从暗处被照亮、扫描线扫过、聚光灯打开 | 熄灭、余晖 | 电影、悬疑、揭秘 |
| **手绘** | 笔尖画出线条、涂色填充、划掉重写 | 橡皮擦掉 | 教学、轻松、故事 |

代码要点（`MJ.lib`）：
```js
// 错峰出场：n 个元素在 0.8 秒内依次弹出
for (let i = 0; i < n; i++) { const k = stagger(u, i, n, t0, 0.8, 0.5, E.back); /* 用 k 控制缩放和透明度 */ }
// 线条沿路径"画出来"：setLineDash + lineDashOffset
c.setLineDash([len, len]); c.lineDashOffset = len * (1 - pr(u, t0, 1.2, E.inOut)); c.stroke(); c.setLineDash([]);
// 盖章：先放大到 1.4 倍、透明，0.18 秒砸到 1 倍，配 stamp 音效
const k = pr(u, t0, 0.18, E.out); c.globalAlpha = k; const s = mix(1.4, 1, k); /* 以印章中心缩放 */
// 生长：用 0→1 的进度裁剪绘制范围（clip 一个逐渐变大的矩形 / 圆）
```

## 四、镜头和转场

**让画面有"镜头感"**：现在大多数场景是固定机位，像幻灯片。至少给招牌镜头加运镜：
```js
// 在一个比画面大的"世界"里移动镜头：缓慢推近主角
c.save();
cam(c, { x: mix(960, 1240, k), y: mix(540, 470, k), zoom: mix(1, 1.8, k), rot: mix(0, -0.03, k) });
drawWorld(c, u);            // 世界坐标里画所有东西
c.restore();
drawCaptions(c, u);         // 字幕在镜头外面画，不跟着动
```
- **推近**：揭示细节、强调；**拉远**：揭示规模、收尾；**横移**：从 A 走到 B（因果、过程）；**轻微旋转 + 推近**：紧张、悬疑。
- 运镜要慢（2–4 秒），用 `E.inOut`。

**转场不只有淡入淡出**（project.json 的 `transition`：`fade / cut / wipe / circle / slide / pixel / glitch`）。更好的转场是**在场景里做**：
- **匹配剪辑**：上一镜结尾的某个元素（一个光点、一个字），正好是下一镜开头的元素，位置和颜色一样 → 用 `cut` 衔接，观众感觉是连续的。
- **推入**：上一镜结尾镜头推进某个物体，下一镜从这个物体"里面"开始。
- **一句话贯穿**：上一镜的最后一句字幕留在原位，下一镜在它周围出现新画面。

## 五、字幕样式（按美术方案选，不必每条都居中淡入）

| 样式 | 怎么做 | 适合 |
|---|---|---|
| 居中淡入 | `captions()` 默认 | 沉静、哲思 |
| 打字机 | `typed(s, u, t0, cps)` 逐字出现 + 光标 | 科技、对话、悬念 |
| 逐字弹出 | 每个字用 `stagger` 缩放弹入 | 轻松、活泼 |
| 贴着元素 | 字幕跟着画面里的主角走（放在主角旁边） | 解说图表、指认 |
| 大字报 | 关键句占满半屏，其他句子很小 | 金句、转折 |
| 手写描边 | 文字先描边画出（strokeText + dash）再填色 | 手绘、教学 |
| 竖排 | 逐字竖着排 | 水墨、东方 |

字幕永远要**看得清**：浅底深字、深底浅字；画面复杂时给字幕后面加一条半透明底。

## 六、画风（风格包）怎么选

`node bin/mjv.mjs styles` 或工作台里看样张。16 套，可以在 theme 里继续改：

| 气质 | 风格包 |
|---|---|
| 沉静、宏大、宇宙 | `dark-gold` 暗金星尘、`synthwave` 合成波 |
| 电影、叙事、悬念 | `cinema` 电影感（遮幅 + 调色 + 光晕 + 颗粒）、`noir` 黑白电影 |
| 手作、亲切、故事 | `sketchbook` 手绘速写（整帧勾墨线、12 帧抖动）、`kraft` 牛皮纸、`paper` 纸本 |
| 艺术、人文、厚重 | `oil-painting` 古典油画（笔触 + 厚涂 + 画布）、`ink` 水墨宣纸 |
| 温柔、治愈、自然 | `watercolor` 水彩（分层平涂 + 晕染 + 纸纹）、`pastel` 马卡龙 |
| 教学、原理 | `chalkboard` 黑板、`blueprint` 工程蓝图 |
| 技术、黑客 | `neon` 霓虹终端 |
| 理性、数据 | `swiss` 极简瑞士 |
| 轻松、反差、吐槽 | `retro-pop` 复古波普 |

**后期画风**（theme 的 `post`）可以和任何配色组合：`{ "preset": "handdrawn" | "film" | "oil" | "watercolor" }`，参数见 `engine/post.js` 开头。例如 `paper` 配色 + `film` 后期 = 暖色调的纪录片感。
注意：`oil` 会把很细的深色线条和小字吃掉，浅底上慎用；`watercolor` 会让渐变背景出现色带，配纯色底；`handdrawn` 会把动作降到每秒 12 帧，这是故意的。

## 七、什么时候问用户，怎么问

**一定要问**（等用户回答再继续）：
1. **美术方案**：给 2–3 个差别明显的方案，每个配 1–2 张静帧（先用 `mjv_stills` 在一两个关键镜头上把方案做出来），让用户挑。不要只用文字描述。
2. **落点句 / 结尾**：如果文案里的金句有多个候选。
3. **图片来源**：需要真实图片（书封、产品、人物）而用户没给时，问是用户提供、AI 生成还是改成示意图。
4. **大改动**：要推翻已确认的文案或方案时。

**不要问**（自己决定，做完给用户看结果）：用哪个缓动、字号具体多大、粒子多少个、代码怎么写、参数怎么调。

**怎么问**：一次问完，选项编号，每个选项一句话说清区别，附静帧。例如：
> 美术方案三选一（静帧见下）：
> A. 手绘速写：像在笔记本上边画边讲，亲切、轻松
> B. 电影感：宽银幕 + 暗调，像揭秘纪录片，有悬念
> C. 复古波普：黄底撞色，像漫画，适合吐槽式的语气
> 我倾向 B，因为这期的转折比较多。

**交付静帧前自检**：字幕都看得清吗？每个镜头遮住字幕能看懂吗？和以往作品（`mjv_history`）比有三项不同吗？用户在工作台的意见（`mjv_notes`）都处理了吗？
