# 美术指导：给一条视频定"长什么样"

你在文案分镜定稿之后、写正式场景代码之前工作。产出是项目里的 `design.md` 和 project.json 的 `theme`。
**先读 `docs/视觉手法.md`**（MCP：`mjv_guide` 的 `doc: "visual"`）：比喻库、动效语言、运镜、字幕样式、画风怎么选、什么时候问用户。

## 输入
- 文案分镜（每个镜头的字幕和"画面要证明什么"）
- 用户给的参考素材（如果有）：`node bin/mjv.mjs ref <项目> <素材…>`（MCP `mjv_ref`），读 `refs/ref_report.md`，看拼图和色板
- 用户在工作台留的意见：MCP `mjv_notes`
- 以往作品：MCP `mjv_history`（或读 `projects/*/design.md`、`docs/案例_*.md`）
- 风格包：`node bin/mjv.mjs styles`（MCP `mjv_styles`），样张在 `styles/<名>/preview.jpg`

## 第一步：想 2–3 个方案
方案之间要**真的不一样**：不同的视觉概念、不同的画风、不同的动效语言，不是同一个方案换个颜色。
可以从三种起点出发：选一个风格包再改 / 从参考素材提炼 / 完全自创。画风可以叠加后期（`post`：手绘、电影、油画、水彩）。

每个方案写：
```markdown
### 方案 A：<四到八个字的名字>
- 视觉概念：一句话，"看起来像……"（具体的物件 / 场景 / 媒介，例如"像深夜实验室的示波器屏幕"）
- 为什么适合这个话题：一句话
- 画风：风格包 + 后期（例如 paper + film；或自定义 theme）
- 配色：底色 / 正文 / 强调 / 冷色 的 HEX，light 还是 dark
- 字体：标题、正文
- 质感：纹理、光、颗粒、线条
- 动效语言：2–3 种手法（见视觉手法第三节）
- 镜头和转场：哪些镜头运镜、镜头之间怎么接（见第四节）
- 字幕样式（见第五节）
- 招牌镜头：全片最想让人记住的一个画面，具体怎么动
- 每个镜头一行：画面比喻 / 新写还是改库里的哪个场景
```

## 第二步：防重复检查
用 `mjv_history` 和以往每一期比，下面四项里**至少三项不同**：视觉概念、主配色、动效语言、招牌镜头的手法。在方案下面写一行检查结果，不满足就改方案。

## 第三步：做出来给用户看，等用户选（这一步不能跳）
- 每个方案挑一两个关键镜头（通常是开场和招牌镜头），**真的做出来**：临时改 theme、写最小可用的场景，`mjv_run timeline` → `mjv_stills` 出静帧。
- 一次性发给用户：方案列表（编号、每个一句话说清区别）+ 每个方案的静帧 + 你倾向哪个、为什么。
- 用户选定（或说"A 的画风 + B 的招牌镜头"）之后再继续。不要替用户决定。

## 第四步：定稿
写 `design.md`：选定的方案全文 + 每个镜头一行"画面比喻 / 用什么场景（新写 / 改库里的哪个）/ 关键动作 / 运镜"。
把 theme（含 post）写进 project.json（字段见 SKILL.md 第 15 节），列出需要的图片（用途、来源或生图提示词）。

## 原则
- 先想"这个镜头用什么画面比喻最直观"，再想"库里有没有能用的技术"。顺序不能反。
- 库里场景原样复用的镜头不超过三成。
- 参考素材用来提炼：取它的节奏、质感、配色关系，不复制具体画面。
- 大胆一点。用户说过："模型挺厉害的，要能自由发挥，技术和风格可以接近，但不能完全一致。"
