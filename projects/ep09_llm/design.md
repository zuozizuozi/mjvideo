# EP09 美术方案（补记）

- 视觉概念：宇宙 / 星尘，"像在夜空里看一个想法慢慢成形"
- 配色：dark；底 #12172c→#04050c，正文 #f2efe6，强调暖金 #f3c46b，冷色 #78b4ff
- 字体：思源宋体 Black / Bold
- 质感：无纹理，漂浮微尘，大量发光（lighter 叠加）
- 动效语言：粒子聚合 / 散开；光点呼吸；逐句淡入并轻微上移
- 镜头和转场：基本不运镜，镜头之间淡入淡出
- 字幕样式：居中或画面下方，关键词金色发光
- 招牌镜头：光点从混乱汇聚成发光人形；"猜，下一个字"粒子聚字
- 起点：参考抖音"Vibe知识大赏"《熵》，自创
